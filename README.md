# Anatomy-RU

**Anatomy RU 3D** — Android-приложение для изучения анатомии на русском языке.

## Первый этап
Рабочий Android-каркас, русско-латинская карточка структуры, переключение систем и CI-сборка APK через GitHub Actions.

## Следующий этап
Подключение настоящего glTF/GLB 3D-движка и анатомических моделей, затем выбор отдельных костей/мышц, изоляция, скрытие и поиск.

## Сборка
GitHub Actions автоматически собирает debug APK после push в `main`.
